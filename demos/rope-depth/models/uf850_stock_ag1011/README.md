# UF850 + stock AG1011 visual FK model

This archive includes the complete 14-part visual geometry and kinematic chain used by the demo: seven UF850 arm meshes and seven stock gripper meshes. Keep the directory layout unchanged so the URDF's relative STL paths resolve.

The URDF is a derived visual/FK subset, not a complete dynamics or collision-planning model. Inertias, collision geometry and hardware-control plugins are omitted. Nominal geometry does not establish absolute physical accuracy.

Upstream: https://github.com/xArm-Developer/xarm_ros/tree/cf51617d98bc55a88d9aa735acfa43a0bbb8e425

Original STL bytes and UFACTORY license are retained. UPSTREAM_SOURCES.json lists exact upstream URLs and SHA256 values.
